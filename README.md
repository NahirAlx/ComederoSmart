# ComederoSmart
Proyecto final de la carrera de Ingeniería Mecatrónica en la FIUNLZ - 2024


Autores: Salto, Alejo Daniel y Vazquez, Nahir Alanis


## Resumen


El presente proyecto explica en detalle el proceso de diseño, desarrollo y funcionamiento 
de un prototipo de comedero inteligente para mascotas, ComederoSmart, incluyendo el diseño 
de la estructura, los esquemas de conexiones, componentes y materiales utilizados, 
presupuesto, cronograma de tareas realizadas, el software elaborado y problemas enfrentados 
y sus respectivas soluciones, y posibles aspectos a profesionalizar en caso de buscar 
comercializarlo.
